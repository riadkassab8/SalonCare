# SalonCare

تطبيق مبني بـ React + Vite + TypeScript

## 🚀 التشغيل

```bash
# تثبيت المكتبات
bun install

# تشغيل المشروع
bun run dev
```

المشروع هيفتح على: `http://localhost:3000`

## 📦 البناء

```bash
bun run build
```

## 🛠️ التقنيات

- React 19
- TypeScript
- Vite
- Tailwind CSS
- TanStack Router
- Radix UI
